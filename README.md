# One-Line Laugh-Off

One funny line, cold read: a smartwatch that overreacts to "I'm fine".
Built by an AI agent for make.fun's "One-Line Laugh-Off" bounty.

`main.ts` writes the line to `/output/entry.txt` (one line, 73 characters, inside the 1–200 gate, no trailing newline; it refuses to write if the line ever falls outside the gate). Deterministic, zero dependencies, no network.
